# Odalys Rendón Peláez — Portafolio

Sitio web personal construido con HTML5 semántico, CSS3 moderno y JavaScript vanilla.

## 🚀 Demo en vivo
[tu-usuario.github.io/portafolio](https://tu-usuario.github.io/portafolio)

## ✨ Características
- HTML5 semántico
- CSS3 con custom properties y mobile-first
- JavaScript ES6+ sin frameworks
- Menú hamburguesa, modo oscuro, smooth scroll y formulario con validación
- Tres proyectos con demo propia (carpeta `proyectos/`)
- Accesible (skip link, foco visible, ARIA)

## 🛠️ Tecnologías
- HTML5, CSS3 (Grid, Flexbox, custom properties)
- JavaScript ES6+ (módulos)
- Git y GitHub
- Lighthouse para auditoría

## 💻 Correr localmente
Abre `index.html` con Live Server (VS Code) o ejecuta `python -m http.server` en la carpeta y visita `http://localhost:8000`.
